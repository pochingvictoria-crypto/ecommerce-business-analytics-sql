# E-commerce Business Analytics with SQL & Python

## Project Overview

This project demonstrates an end-to-end business analytics workflow using the Olist E-commerce Dataset.

Instead of focusing only on SQL queries, this project starts from business questions, defines KPIs, extracts data using SQL, visualizes insights with Python, and provides business recommendations.

---

## Objectives

- Translate business problems into analytical questions
- Design executive KPIs
- Extract and transform data using SQL
- Visualize business insights using Python
- Support business decision-making through data analysis

---

## Project Structure

- Chapter 1 – Executive KPI Dashboard
- Chapter 2 – Sales Analytics
- Chapter 3 – Customer Analytics
- Chapter 4 – Product Analytics
- Chapter 5 – Logistics Analytics
- Chapter 6 – Customer Experience Analytics

---

## Dataset

Brazilian E-commerce Public Dataset by Olist
